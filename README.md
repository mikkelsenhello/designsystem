# Designsystem

A rebrandable, reusable design system: CSS-variable tokens (global → theme → component) wired into Tailwind, with React components that only ever reference tokens. Rebranding means swapping one theme file, not editing components.

Consumed by other projects as a git dependency pinned to a tag:

```json
"designsystem": "git+https://github.com/mikkelsenhello/designsystem.git#v0.1.0"
```

- [PLAN.md](PLAN.md): architecture, phases and decisions already made
- [CLAUDE.md](CLAUDE.md): standing rules for working in this repo
